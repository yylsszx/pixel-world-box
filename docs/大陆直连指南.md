# 大陆直连指南——稳定打开与游玩 PWB

## 三个入口，先说结论

| 入口 | 地址 | 大陆可用性 | 云端功能 |
| --- | --- | --- | --- |
| **GitHub Pages（首选游玩入口）** | https://yylsszx.github.io/pixel-world-box/ | 稳定可达 | AI 神谕浏览器直连大陆厂商（见下表，无需任何后端）；云存档/国策/编年史需云端后端可达 |
| **全功能版（Worker 托管）** | https://pwb-oracle-relay.yeyilin2010.workers.dev | 受 DNS 污染，多数大陆线路打不开（非部署故障） | 打开即全功能：同源 AI 神谕/云存档/中枢国策/编年史零配置 |
| **本地模型** | 游戏「设置 → 厂商接入 → 本地模型」 | 离线可用 | 浏览器端推理，零网络零密钥（手机端较慢） |

**打不开全功能版的原因（事实）**：`workers.dev` 域名在大陆网络被 DNS 污染（解析到假地址）+
连接阻断——这是线路层面的物理限制，任何部署侧代码都无法解开。两个入口的游戏本体完全一致
（同一份代码自动部署），在 GitHub Pages 入口游玩不损失任何游戏内容。

| Naive AI 官方端点 | ✗ 白名单制 | api.naive.ai 只放行 platform.naive.ai（实测预检 400 Disallowed CORS origin）——需可达的云端后端转发 |
| 讯飞星火 / 腾讯混元官方端点 | ✗ 不支持 | 预检 403 / 404——需云端后端转发 |

**要点**：智谱 GLM 官方、Naive、星火、混元的跨域拦截发生在厂商服务器上，不是游戏配置问题，
换网络换设备同样被拒。GLM 的开权重模型（GLM-5.3 / 5.3-Flash 等）托管在硅基流动，一个 Key
直连用上同款 GLM——这是大陆静态部署下用 GLM 的正路。直连失败时游戏会自动降级云端后端兜底，
并给出上述事实指引。

## 云存档 / 中枢国策 / 编年史（需要云端后端可达）

这三项走 PWB 云端服务（Cloudflare Worker）：

- 线路可达时（海外网络 / 部分移动网络）自动使用，零配置；
- 不可达时自动降级：云存档不可用（本地存档照常）、中枢用本地人格、编年史用本地简史——功能不缺失，只是不联网；
- 全功能版入口打开的玩家同源直连，天然全功能。

## 根治：自定义域名三步走（约 10 分钟，一次性）

前提：一个属于你的域名（任意注册商，约 ¥10-60/年，**无需 ICP 备案**——服务由 Cloudflare 全球边缘节点提供，不落地大陆）。

1. **添加站点到 Cloudflare**：dash.cloudflare.com → 添加站点（Add a site）→ 填你的域名 → 选 Free 计划 → 按提示到域名注册商把 NS 服务器改成 Cloudflare 给的两条 → 等生效（几分钟到几小时，站点页显示「活动」即成）。
2. **绑定 Worker 自定义域**：Cloudflare 仪表盘 → Workers & Pages → `pwb-oracle-relay` → 设置（Settings）→ 域和路由（Domains & Routes）→ 添加（Add）→ 自定义域（Custom Domain）→ 填 `relay.你的域名`（任意子域即可）→ 确认，等证书签发（通常 1-2 分钟）。
3. **浏览器直接打开你的域名**：绑定后 `https://relay.你的域名/` 就是完整游戏（同源全功能）；GitHub Pages 入口想用云端功能（含 Naive 等白名单厂商的神谕转发），把 `https://relay.你的域名` 填进游戏「设置 → 厂商接入 → 云端后端」→ 点「测试连通」显示连通即成。

## 常见问题

- **测试连接显示失败但功能正常？** 测试是即时实测（绕过缓存、单次探测），功能层有 60s 探测缓存与直连失败 60s 冷却（同一端点失败后一分钟内自动走云端后端，不再重撞跨域墙）；以「测试连通」结果为线路参考。
- **GLM 官方 Key 能直接用吗？** 不能——官方端点跨域被拦在智谱服务器侧。要么用硅基流动的 Key（其上托管同款开权重 GLM），要么按上节绑定自定义域名走云端后端转发官方端点。
- **绑定后还是不稳？** ① 确认 Cloudflare 站点页显示「活动」（NS 未生效前域名不可用）；② 换个子域名再绑（DNS 缓存）；③ 个别地区运营商对 Cloudflare IP 段限速属网络环境问题，可稍后重试或换网络（如切流量）。
- **换设备后还要重新填吗？** 厂商 Key 与云端后端配置都存在浏览器 localStorage——同设备免重填；换设备把地址照抄一遍即可（云存档另有备份码体系，与此无关）。
- **全功能版和 GitHub Pages 版内容有差别吗？** 没有差别——同一份代码自动部署到两处；全功能版的优势只在「打开即云端全功能零配置」。
