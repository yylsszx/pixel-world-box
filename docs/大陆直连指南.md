# 大陆直连指南——稳定使用 PWB 云端后端

## 问题

PWB 云端后端默认部署在 `*.workers.dev`，该域名在大陆网络普遍不稳定（DNS 污染 / SNI 阻断）。
游戏本体托管在 GitHub Pages，不受影响；云端功能（神谕云端 AI / 云存档 / 中枢国策 / 编年史）在大陆线路可能探测失败并自动降级——功能不缺失，但拿不到云端算力。

## 根治：自定义域名三步走（约 10 分钟，一次性）

前提：一个属于你的域名（任意注册商，约 ¥10-60/年，**无需 ICP 备案**——服务由 Cloudflare 全球边缘节点提供，不落地大陆）。

1. **添加站点到 Cloudflare**：dash.cloudflare.com → 添加站点（Add a site）→ 填你的域名 → 选 Free 计划 → 按提示到域名注册商把 NS 服务器改成 Cloudflare 给的两条 → 等生效（几分钟到几小时，站点页显示「活动」即成）。
2. **绑定 Worker 自定义域**：Cloudflare 仪表盘 → Workers & Pages → `pwb-oracle-worker` → 设置（Settings）→ 域和路由（Domains & Routes）→ 添加（Add）→ 自定义域（Custom Domain）→ 填 `relay.你的域名`（任意子域即可）→ 确认，等证书签发（通常 1-2 分钟）。
3. **游戏内填入**：设置 → 厂商接入 → 中继后端 → 填 `https://relay.你的域名` → 点「测试连接」显示「✓ 可达 · 延迟 · AI✓ · 云存档✓」即成——神谕 / 云存档 / 国策 / 编年史全部端点即刻走你的域名稳定直连。

## 为什么这是根治

- 自定义域走你自己的域名解析，完全不经过 `workers.dev`——大陆线路对自有域名的 Cloudflare 边缘可达性远好于被污染的 workers.dev；
- Worker 侧零改动（CORS 全放行、不校验 Host）——绑定即生效，不需要重新部署；
- 游戏侧已就绪（v0.73 起）：官方中继多镜像竞速探测 + 用户中继最高优先级，填入即全端点切换；「测试连接」可随时实测。

## 不想买域名的替代路径

| 路径 | 说明 |
| --- | --- |
| 官方云端中继自动探测 | 每次云端操作自动竞速探测（60s 缓存），线路通时即用；不通自动降级（本地简史 / 本地人格 / 本地存档），功能不缺失 |
| 自定义厂商直连 | 厂商接入选 OpenAI 兼容 / Anthropic，填大陆可达且允许浏览器跨域的厂商端点 + Key——浏览器直连厂商，不经 Worker |
| 本地模型 | 厂商接入选本地模型——浏览器端推理，零网络零密钥 |
| 自建中继 | 有内网 / 海外服务器可跑仓库 `oracle-server/`，地址填入「中继后端」 |

## 常见问题

- **测试连接显示 ✗ 但功能正常？** 测试是即时实测（绕过缓存、单次探测），功能层有 60s 探测缓存与多镜像竞速重试，边界情况略有差异；以「测试连接」结果为线路参考。
- **绑定后还是不稳？** ① 确认 Cloudflare 站点页显示「活动」（NS 未生效前域名不可用）；② 换个子域名再绑（DNS 缓存）；③ 个别地区运营商对 Cloudflare IP 段限速属网络环境问题，可稍后重试或换网络（如切流量）。
- **换设备后还要重新填吗？** 中继后端配置存在浏览器 localStorage——同设备免重填；换设备把地址照抄一遍即可（云存档另有备份码体系，与此无关）。
